# 문서 자동 분류기 (교육용 프로토타입)

문서의 제목과 내용에 들어 있는 키워드를 보고 업무별 폴더로 나눠 보여 주는 웹 페이지입니다.
실제 파일은 옮기지 않습니다. 문서는 모두 가상 데이터입니다.

## 여는 방법
`index.html` 을 더블클릭합니다.

## 분류 규칙 (교육용 가상 기준, `logic.js`)
| 폴더 | 키워드 |
|---|---|
| 안전점검 | 안전 · 점검 · 진단 · 위험 |
| 행사운영 | 행사 · 축제 · 체험 · 참가 · 운영 |
| 시설보수 | 보수 · 수리 · 교체 · 설비 · 공사 |
| 비상대응 | 비상 · 훈련 · 대피 · 재난 · 연락망 |
| 기타 | 위 키워드가 하나도 없을 때 |

- 제목에 있는 키워드는 2점, 내용에 있는 키워드는 1점으로 셉니다.
- 점수가 가장 높은 폴더로 보냅니다. 동점이면 표에서 위에 있는 폴더가 이깁니다.

## 확인 방법
- [ ] D-01 `index.html` 을 열면 가상 문서 6건이 폴더별로 나뉘어 보인다
- [ ] D-02 제목에 "간판 보수"를 넣고 추가하면 '시설보수' 폴더에 바로 들어가고, 새로고침해도 남는다
- [ ] D-03 키워드가 없는 문서(예: "점심 메뉴")는 '기타' 폴더로 간다

## 파일
- `index.html` : 화면 구조
- `style.css` : 디자인
- `logic.js` : 분류 규칙만 (화면 코드 없음)
- `app.js` : 화면 동작 (목록 그리기, 문서 추가)
